# 2026-09-04

## 账号管理面板滚动问题修复

**问题**：`tools/account` 路由下，除"网站账号管理"（WebsitePanel）外，其他 7 个列表（通用、店铺、社媒、邮箱、手机号、企业信息、证件信息）滚动失效，多余行被裁掉。

**根因**：在 `src/pages/tools\account\panels\*Panel.tsx` 中，除 WebsitePanel 外，所有 panel 的滚动容器都使用了：
```html
<div className="flex-1 overflow-hidden">
```
该写法只在内容超出时**裁剪**而不**滚动**，导致表格内容溢出但无法访问。对比可工作的 WebsitePanel 第 701 行 `flex-1 overflow-y-auto scrollbar-hide` 即可确认。

**修复**：将 7 个 panel 中：
```html
<div className="flex-1 overflow-hidden">
```
替换为：
```html
<div className="flex-1 min-h-0 overflow-y-auto scrollbar-hide">
```
- `overflow-y-auto` 启用垂直滚动
- `min-h-0` 是 flexbox 中的关键修复：flex 子项默认 `min-height: auto`，会撑满内容高度，使 `overflow-y-auto` 失效；显式设置 `min-h-0` 允许子项缩小到内容之下，从而启用滚动
- `scrollbar-hide` 隐藏滚动条样式（与 WebsitePanel 一致，该类已在 `src/styles/theme.css` 中定义）

**改动文件**：
- `src/pages/tools/account/panels/GeneralPanel.tsx`
- `src/pages/tools/account/panels/ShopPanel.tsx`
- `src/pages/tools/account/panels/SocialPanel.tsx`
- `src/pages/tools/account/panels/EmailPanel.tsx`
- `src/pages/tools/account/panels/PhonePanel.tsx`
- `src/pages/tools/account/panels/CompanyPanel.tsx`
- `src/pages/tools/account/panels/CredentialPanel.tsx`

**验证**：
- 仅修改 CSS class，未动任何业务逻辑，不会引入运行时异常
- 滚动只在 panel 内发生，外部层级（panel 根 `h-full overflow-hidden`、index.tsx 中 `flex-1 overflow-hidden p-4`、Content.tsx 容器）均保持 `overflow-hidden`，不会产生窗口垂直滚动条
- `tsc --noEmit -p tsconfig.app.json` 通过，零编译错误

**复用提示**：未来在 flex 列布局中给 `flex-1` 子项加垂直滚动时，标准写法是 `flex-1 min-h-0 overflow-y-auto scrollbar-hide`，不要漏掉 `min-h-0`。
