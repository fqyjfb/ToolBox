### 关键结论
1. **P0 数据正确性**：`NetworkTab.tsx` 的 `DEFAULT_CONFIG`（占位 `xxx` 地址）与 `electron/lib/config.cjs` 的真实默认值（`fqyjfb`）不一致，且前端用"≠DEFAULT_CONFIG"判断自定义，导致默认值被误判为用户自定义。
2. **P0 非法嵌套**：`SettingRow` 用 `<span>` 包 label，而 `GeneralTab` 传入 `<div>`。
3. **P1 一致性**：7 个子页头部 4 种写法；主按钮 3 套风格（primary / gray-800 / orange-500）；`SettingSection/SettingRow` 仅 2/7 复用；加载态 3 种、空状态 0 种。
4. **规范违规**：几乎全量使用 `bg-white dark:bg-gray-800` 硬编码（DESIGN_RULES 明令禁止）；6 文件超 300 行；`GeneralTabProps` 25 个（限 8）；`SyncTab` 全量订阅 `useSyncStore()`（规范反例）；12 文件均未用 `@/` 别名。
5. **功能缺口**：悬浮窗只能改不能增删、无空状态、保存按钮作用域与位置错位；未登录时多处静默 return 无反馈。

## 审计报告复核 + 优化方案（只读，未改代码）

- 产出：`doc/设置页面优化方案.md`（复核版，结论以该文件为准）

### 对首版报告的 5 处修正
1. **网络配置降级 P1**（原 P0）：`config.cjs:116/154` 显示 `getSettings()` 返回「合并后真实默认值」而非用户覆盖值。另修正两处事实错误——`iconCache.ttl` 两端**实际一致**（7天=604800000）；`xxx` 占位符仅在点击「默认」后可见，非常驻。
2. **`@/` 别名不建议单独改**：全项目仅 `pages/tools/notes/` 7 个文件用 `@/`，其余全用相对路径；单独改设置模块会与 95% 代码割裂。
3. **复杂度阈值**：DESIGN_RULES 自相矛盾（L204 ≤300 / L684 ≤500）。改为存量按 500、新增按 300 → 需拆分文件从 6 个收敛到 2~3 个（仅 StorageTab 657 / SyncTab 594 / Settings 523 超标）。
4. **图标统一色需产品确认**：`--color-primary` 是**自动反色**令牌（浅色 #18181B 近黑 / 深色 #EAF1F8 近白），把 `text-blue-600` 换成 `text-primary` 会让图标由蓝变黑，属视觉变更。
5. **不预设新建组件**：`ui/` 下无 Button；空状态仅 2 处需求 → 不新建，内联即可。

### 已验证的关键事实（供后续复用）
- **令牌替换安全**：`bg-card`/`border-border`/`bg-bg-secondary`/`text-text-primary` 与现有 `gray-*` 色值差异 ≤1 灰阶，替换后可去掉 `dark:` 前缀。
- `button-text: var(--color-bg-primary)` 是**自动对比度**设计，所以 `bg-primary text-button-text` 在双模式下都正确。
- Tailwind v3.4.19 → 同属性类名冲突时按 CSS 生成顺序生效，`.px-3` 在 `.px-2` 之后 → `Select` 传入的 `px-2 text-xs` 覆盖**失效**（真实缺陷）。
- `ToggleSwitch` 无 `disabled` 属性，而 `ShortcutRow` 依赖冲突时禁用 → 暂不强制复用。
- vite.config.ts 已配 `@` alias（可用，只是项目未普及）。

## 通用设置「自动锁定」行布局修复（已改代码）

- 根因：`Select` 容器默认 `w-full`（`width:100%`），在 `SettingRow` 右侧 flex 项中解析为整行宽度 → 撑破行宽，`ToggleSwitch` 的开关文字被压到最小内容宽度（中文单字宽）而竖排，开关也被顶出与其他行的对齐线。
- 修复 1：`GeneralTab.tsx` 给自动锁定的 `Select` 加宽度约束（`w-28` 类）替代 `w-full`。
- 修复 2：`ToggleSwitch.tsx` 文字加 `whitespace-nowrap`，并给外层容器加 `shrink-0`，防止被 flex 压缩。
- 验证：`tsc` 0 错误、`eslint` 0 告警、`vite build --no-emptyOutDir` ✓ built in 1m 2s。
- 注意：PowerShell 在本会话 stdout 会被吞掉，构建校验需把日志重定向到项目内文件再 Read。
