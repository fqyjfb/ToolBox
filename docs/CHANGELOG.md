# 更新日志

## v2.2.4

- 新增记事本聊天功能，支持对话模式切换，在左侧笔记列表点击"对话"进入聊天界面
- 消息支持发送、标记完成、多选操作，按日期分组展示
- 支持将消息移动到多种目标文件：稍后阅读、阅读清单、观影清单、购物清单、日记本、归档
- 聊天记录文件命名为中文（对话.md），自动按日期生成分组标题

## v2.2.3

- 修复右键菜单二级菜单位置问题，新增智能边界检测确保菜单完整显示
- 优化右键菜单样式，采用紧凑型设计
- 新增窗口大小响应，使用 ResizeObserver 动态调整二级菜单位置
- 提升代码质量，添加防御性编程和资源清理
- 优化数据同步，新增启动时静默同步和增量检查功能

## v2.2.2

- 修复自动锁定功能，使用 Windows API 获取系统空闲时间，确保前台后台都能正确检测用户活动
- 优化系统活动检测策略，动态调整检测间隔，减少 CPU 消耗
- 清理自动锁定相关冗余代码，移除窗口级别活动监听
- 移除重复依赖 @electron/rebuild（electron-builder 已内置）
- Account Panel 组件错误日志统一使用 loggerService
- 修复快启动拖拽功能，使用 Electron webUtils.getPathForFile() 方法正确获取文件路径
- 修复日志窗口滚动条问题，采用更紧凑的布局设计
- 删除 electron/logs 目录下未使用的冗余文件，将日志页面从 src/pages/tools/logs 移动到 src/pages/logs
