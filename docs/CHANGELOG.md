# 更新日志

## [3.1.2]

### 新功能

- 首页卡片右键菜单新增「新增」项：待办 / 备忘录 / 定时提醒 / 快捷回复 / 云剪贴板，与卡片「+」按钮同一入口
- 卡片数据行右键支持新增 / 编辑 / 删除，复用各工具页同一套表单与 service，提醒的编辑与删除照常同步计划任务
- 自定义主题新增四套预设：晨曦紫（浅·紫）、落日橙（浅·橙）、极光青（深·青）、石墨金（深·金）
- 存储页图标缓存新增「磁盘缓存」子区块，分别统计远程图标与桌面应用提取图标；支持按通用 / 插件 / 应用分类清理
- 托盘右键菜单顶部新增「新建」子菜单，收纳新建待办 / 备忘 / 提醒

### Bug 修复

- 修复 Toast 在同一毫秒内连续触发时 id 冲突被误移除；定时器副作用移出状态更新函数
- 修复 `onSettingChanged` 单槽回调被覆盖：App 卸载时注册空函数会顶掉 `baseApi` / `PluginService` 的回调，导致改网络配置后缓存失效从未生效；改为多播并返回退订函数
- 修复首页日历弹窗底部多余按钮容器，以及小窗口模式最右列被裁剪（网格列可压缩，日期与字号随宽度等比缩放）
- 修复首页卡片拖拽时浮层落在光标右下方约一格：`PageTransition` 的 transform 层成为 fixed 定位包含块，浮层改用 `createPortal` 挂到 `body`
- 修复首页待办事项卡片混入已完成条目：仅展示未完成，标记完成后即时移出并同步数量
- 修复自定义主题预设点击后只有实时预览变色、跨基色预设出现半套混搭、未保存离开设置页残留「基色已改、配色未改」
- 修复深色自定义主题重启后以浅色基色加载：明暗基色随主题配置一并持久化
- 修复自定义主题下滚动条仍按系统明暗翻转、Toast 提示条完全不跟随配色（`--color-toast-*` 变量链接通，按底色明暗自动派生文字与边框色）
- 修复设置页「图标缓存」桌面端恒为 0 与统计虚高；「清理插件 / 通用缓存」按钮恒禁用导致磁盘图标无法按类型清理
- 修复托盘「新建」子菜单首次点击只跳转、弹窗要第二次点击才打开：预加载层早到的消息改为暂存，页面注册回调时补发
- 修复插件商店图标未优先使用包内图标（改按 iconUrl 目录名匹配，12 个全部命中）
- 修复记事本侧边栏点击图片后右侧内容区空白、图片无法显示：`local-media` 协议白名单原先从 `settings.json` 读 `notes_view_path`（该键无任何写入方），白名单退化为仅放行图标缓存目录，笔记内图片一律被判越界返回 403；改为复用 `notesService.getAllowedRoots()`，主根 / 视图根 / 对话根与 IPC 层同源
- 修复记事本图片加载失败时无降级也无提示（只表现成空白）：`local-media://` 失败自动回落 `useNotesSelection` 已读好的 blob URL，两者均失败才显示错误提示（`NotesImageViewer` 新增 `onError`）

### 优化

- 启动与首屏：Google Fonts 异步加载、首屏 IPC 与插件加载并行、圆角 PowerShell 延后到页面加载完成、SQLite 首次落盘延后一个 tick

- 移除 App 层重复的 `QueryProvider` 与重复的 `online/offline` 监听，日志订阅去掉每订阅者一次的全量拷贝
- 首页卡片改为按坐标自由布局（桌面图标式）：拖到任意位置自动吸附网格，坐标存档兼容老数据；落点迟滞、占位滑行、浮层抬起等手感打磨
- 五个卡片添加弹窗的内容 / 描述输入框统一为 5px 细滚动条，样式收敛到 `modalTextareaScrollClass` 一处维护
- 记事本滚动条统一为同一套 5px 细滚动条（纵向 + 横向一致）：侧边栏文件树（含节点多时的虚拟列表滚动层）、固定目录 / 收藏 / 最近 / 对话整理、新建菜单下拉，以及编辑器内容区（Markdown 文档的 vditor 内部滚动层、HTML 预览与源码、PDF / Word / Excel 预览）；全局 `.scrollbar-5px` 补齐 `height`，横向不再残留浏览器默认的宽横条
- 自定义主题：重调莫兰迪浅 / 护眼绿 / 深夜蓝的色阶层次并按 WCAG 校准对比度，补齐 `colorMuted` 与 `colorCardValue`，预设按钮新增色卡预览
- 统一自定义配色快照与主窗口空字段兜底，锁屏等独立窗口颜色一致；导入主题配置时校验背景图体积
- 状态标签 / 徽章等约 30 处硬编码状态色改由主题变量驱动，不再按系统明暗翻转
- 新增侧边栏按钮悬浮抬升与按下回弹效果

### 重构

- 备忘录 / 快捷回复 / 云剪贴板工具页的编辑弹窗改用各自 `FormModal`，与新增、首页编辑统一为一套 UI，提交逻辑不变
- 移除全项目 themeKey 强制重渲染模式与 store 中 themeKey 死状态；ColorPicker 清除按钮改用 Lucide 图标，主题卡片内联样式迁移为 CSS 类

## [3.1.0]

### 新功能

- 断网无感切换：所有数据功能（账号/待办/快捷回复/云剪贴板/备忘/提醒）无感切换到本地 SQLite，保存立即响应不假死
- 离线期间增删改记入待补偿队列，恢复网络后自动补偿到云端，删除不复活、数据不丢失
- 断网重启应用保持登录态，不再被强制登出
- 新增网络可达性探测（Supabase 健康检查），假在线（连路由器但出口断）也能正确识别离线
- 全局离线横幅（桌面大窗/小窗/Web/移动四端可见），恢复网络即消失
- 网址导航/热搜/天气离线时展示缓存快照，不再空白
- 同步设置页：离线时禁止切换存储位置并提示，手动同步按钮禁用，显示待补偿条数
- 每日签到入口覆盖全部端：桌面大窗位于右侧头部「大/小窗切换」按钮左侧，小窗位于个人信息行（原「超管」徽章位置，徽章移除），Web 端位于顶部导航栏右侧，移动端位于汉堡按钮左侧；各端共用同一组件
- 未签到点击即签并 toast 反馈；已签到图标高亮并提示「今日已签到 · 连续 N 天」；签到幂等，每个用户每天一条
- 数据仅存云端 `check_ins` 表（不落本地 SQLite、不接入云同步链路），`UNIQUE(user_id, check_in_date)` 数据库级幂等（多端并发同天签到视为已签），RLS 用户隔离；离线时提示需联网
- 记事本小窗模式：只显示对话输入界面（消息列表 + 输入框），侧边栏、标题栏、页签、编辑器、搜索与弹窗一律不渲染；固定走对话视图，即使未切换至对话模式也会读取并刷新消息
- 桌面端首页新增天气卡片：复用头部天气的数据与悬浮详情弹层，不重复请求
- 首页卡片右键菜单新增「打开工具」「添加工具」「移出首页」三项（均带图标）；工具中心右键同步支持「加入首页」「移出首页」
- 新增桌面磁贴顺序持久化（渲染前自动对账，扫描 / 导入 / 增删均无需维护顺序，老数据零迁移）
