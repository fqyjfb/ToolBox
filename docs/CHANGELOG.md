### 优化

- AI 面板样式统一项目主题变量，亮 / 暗 / 自定义配色跟随主窗口；模型选择与请求参数口径对齐设置页
- 移除悬浮球空闲闲聊卖萌语录：气泡内容改由主进程洞察服务统一按真实数据生产，无内容保持安静；支持总开关、分类开关、免打扰时段与推送频控，锁屏不弹
- 悬浮球气泡数据接入零侵入：待办 / 提醒走 sqlite 独立只读连接，天气 / 黄历 / 打卡由渲染层预格式化推快照，主进程不重复发请求、不写业务库
- AI 流式请求补齐首字节 / 空闲 / 总超时与非 SSE 网关回退，思考内容单独通道展示
- 主题与配置变更改为事件推送，面板无需重开即可跟随；隐私类能力默认关闭且关闭即解绑监听
- 进阶功能复用既有 250ms 轮询与剪贴板检测，未新增主进程常驻定时器
- 小橘历史记录「删除」由文字改为 16px 图标按钮，保留悬停提示与无障碍标签
- 命令面板新增截图问答、划词取词、首页、快捷启动、书签导航入口（复用既有动作，与托盘 / 径向菜单同口径）
- 启动提速：OCR（onnxruntime / sharp）与 koffi FFI 改为首次使用时加载，移出启动关键路径
- SQLite 定时落盘改异步写（临时文件 + 原子重命名 + 过期快照作废），不再阻塞主进程，也杜绝库文件半写与新旧快照覆盖；退出 / 切换用户路径仍同步落盘
- 笔记「复制 / 发送到」的 PowerShell 调用异步化，执行期间不再冻结全部窗口（原最长阻塞 10 秒）
- 计划任务 `schtasks` 调用统一加 15 秒超时，系统繁忙时不再卡住启动对账
- 云剪贴板图片检测先比廉价指纹再编码，截图驻留剪贴板时不再每个周期生成大 base64 字符串
- 内存上限保护：邮件读取加 100MB 上限、笔记图片 base64 读取加 20MB 上限，超大文件不再打爆主进程
- 单页渲染崩溃只降级当前页面（可重试 / 回首页），不再白屏整个窗口：路由级错误边界
- 划词导航 / 下载进度回调改多播并返回退订函数，卸载时正确解绑；memo 分类加载加竞态防护
- 翻译历史强制 200 条上限；大结果集工具查询缩短 React Query 缓存驻留
- 主窗口背景节流延迟生效：`hide` 满 30s 才开启后台节流，规避截图 / 快速登录 / 锁屏解锁 / 模式切换等瞬时流程的重绘停顿；`show` 立即还原
- 内存优化默认开启并改为空闲触发：每 30s 巡检，全部窗口隐藏 ≥60s 且距上次回收 ≥10min 时执行主窗 + 浮窗 `window.gc()` 与主进程 `global.gc()`；前后打 `getAppMetrics` 摘要日志，单进程 >300MB 告警
- 悬浮球穿透判定由 250ms 全量轮询改为渲染层事件驱动 + 800ms 看门狗：球体命中状态变化时才上报 IPC，主进程空闲时零唤醒；展开 / 拖拽 / 文件拖入 / 带按钮卡片期间保持可点击
- 悬浮球桌宠空闲 5s 无交互时暂停循环动画（思考 / 说话 / 气泡 / 菜单 / 拖拽期间自动恢复），降低透明窗合成开销
- 常驻预加载缩容：从 4 页（todo / notes / quick-reply / cloud-clipboard）缩为 todo、quick-reply；notes 改为侧栏入口悬停 180ms 意图预加载
- 大窗手动拖拽调整尺寸后自动写回「启动窗口」设置（重启沿用），通用设置页实时同步；小窗、最大化、全屏与贴边停靠不参与记录；默认尺寸统一为 1160×800
