## [3.1.0]

### 优化：快启动界面改为「文件夹化桌面」

- 移除顶部分类胶囊栏，分类改为桌面文件夹磁贴（2×2 迷你图标预览），与未分类应用图标混合排布，交互对齐手机桌面
- 文件夹磁贴与图标支持任意拖拽穿插排序；图标可拖入文件夹归类，文件夹内图标可拖出到桌面或移入其他文件夹
- 点击文件夹展开弹层，可启动 / 拖拽 / 增删夹内应用；拖出弹层面板即移出该文件夹
- 「最常用」智能文件夹移除；「全部」「最近使用」已移除——桌面本身即完整视图，无需单独的「全部」，搜索亦会平铺全量匹配结果
- 搜索激活时自动切换为平铺结果视图（等同旧「全部 + 搜索」）
- 拖拽恒可用：发生排序类拖拽后自动锁定为「自定义」排序，老用户（默认按使用频率）也能直接拖动
- 新增桌面磁贴顺序持久化（渲染前自动对账，扫描 / 导入 / 增删均无需维护顺序，老数据零迁移）

### 新功能：断网无感切换

- 断网后所有数据功能（账号/待办/快捷回复/云剪贴板/备忘/提醒）无感切换到本地 SQLite，保存立即响应不假死
- 离线期间增删改记入待补偿队列，恢复网络后自动补偿到云端，删除不复活、数据不丢失
- 断网重启应用保持登录态，不再被强制登出
- 新增网络可达性探测（Supabase 健康检查），假在线（连路由器但出口断）也能正确识别离线
- 全局离线横幅（桌面大窗/小窗/Web/移动四端可见），恢复网络即消失
- 网址导航/热搜/天气离线时展示缓存快照，不再空白
- 同步设置页：离线时禁止切换存储位置并提示，手动同步按钮禁用，显示待补偿条数

### 新功能：每日签到

- 每日签到入口覆盖全部端：桌面应用大窗口位于右侧头部「大/小窗切换」按钮左侧（标准图标按钮）；桌面应用小窗口位于个人信息行（原「超管」徽章位置，徽章移除）；Web 端位于顶部导航栏右侧（桌面与响应式移动端共用）；移动端位于顶部栏汉堡按钮左侧。各端共用同一组件
- 未签到点击即签并 toast 反馈；已签到图标高亮并提示「今日已签到 · 连续 N 天」；签到幂等，每个用户每天一条
- 数据仅存云端 `check_ins` 表（不落本地 SQLite、不接入云同步链路）：新增 `doc/checkins_supplement.sql`，扁平列匹配 merged schema 约定，`UNIQUE(user_id, check_in_date)` 数据库级幂等（多端并发同天签到视为已签），RLS 用户隔离；离线时按钮提示需联网

### 优化：状态管理统一与冗余清理

- 收藏数据统一为一份缓存：网址导航页与首页收藏栏不再各拉各的，任一侧收藏 / 取消后两侧即时同步
- 待办徽标改用统一查询调度（30 秒），移除独立轮询与多余的全局挂载层

- 统一本地存储读写：侧边栏固定工具、插件安装记录等配置读取更健壮，脏数据不再导致状态异常
