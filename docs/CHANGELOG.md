# 更新日志

## v2.2.2

- **自动锁定功能修复**：修复系统级空闲检测逻辑，使用 Windows API 获取系统空闲时间，确保无论应用在前台还是后台都能正确检测用户活动；
- **性能优化**：优化系统活动检测策略，动态调整检测间隔，减少 CPU 消耗；
- **代码质量提升**：清理自动锁定相关冗余代码，移除窗口级别活动监听（已被系统级检测覆盖）；
- **构建优化**：移除重复依赖 `@electron/rebuild`（electron-builder 已内置）；
- **统一错误处理**：Account Panel 组件错误日志统一使用 `loggerService`；

## v2.2.1

- **代码结构优化**：创建 `ProtectedRoute` 组件和 `renderRoutes` 函数，消除约150行重复路由代码；
- **搜索性能优化**：待办事项页面搜索输入添加 300ms 防抖处理，减少频繁数据库查询；
- **服务层重构**：创建通用 CRUD 服务基类 `BaseService`，减少约40%服务层代码；
- **组件样式优化**：Toast 组件从 styled-components 迁移到 Tailwind CSS；
- **性能优化**：添加工具页面预加载策略，高频工具在浏览器空闲时自动预加载；
- **安全修复**：移除加密密钥硬编码，添加密钥验证机制，强制要求配置环境变量；
- **新增自动锁定功能**：支持设置多种时长，当鼠标和键盘停止活动后自动锁定应用；

## v2.2.0

- **新增锁定功能**：支持通过 Ctrl+L 快捷键锁定/解锁应用，托盘菜单集成，密码安全；

## v2.1.10

- **数据存储与同步修复**：重构数据访问层，统一本地/云端存储接口，确保存储模式切换正常工作；
- **代码质量提升**：修复多个 TypeScript 类型错误，确保类型安全；

## v2.1.9

- **双向数据同步**：云端模式下数据增删改自动同步到本地存储，确保存储管理页面统计数据实时更新；
- **账号管理同步**：待办事项、快捷回复、云剪贴板、网站、通用、店铺、社媒、邮箱、手机号、企业信息、证件信息的增删改操作均自动同步到本地存储；

## v2.1.8

- **数据存储与同步优化**：新增存储模式切换功能（本地/云端），默认设置为云端模式；
- **双向数据同步**：云端模式下数据增删改自动同步到本地存储，确保存储管理页面统计数据实时更新；
- **账号管理页面优化**：添加平台可见性设置功能，支持启用/禁用各账号分类显示；实现 Tab 拖拽排序功能；
- **存储管理页面同步**：统计卡片根据平台可见性设置自动过滤显示

## v2.1.7

- **新增数据离线功能**：实现基于 IndexedDB 的本地数据持久化，支持离线优先架构
- **新增数据同步模块**：实现双向同步、冲突处理、增量同步（基于 updated_at 时间戳）
- **新增同步设置页面**：提供同步开关、模块管理、存储管理等功能
- **数据加密存储**：使用 AES-CBC 加密算法保护敏感数据，格式为 iv:encryptedData（base64编码）
- **多用户数据隔离**：支持用户切换时自动清理旧数据，确保数据安全性
- **待同步操作队列**：离线状态下的操作自动缓存，联网后自动同步
